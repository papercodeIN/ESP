1. ⌛**[IoT Server](<%20UA%20Server/README.md>)** — exposes ESP32 process tags (`ns=1;s=Temperature`, Setpoint, RelayOutput, …) on `://<ip>:4840`; browse it from UaExpert, Prosys or TIA Portal
